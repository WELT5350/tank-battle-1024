# Tank Battle · 1024 Hackathon 2026

经典坦克大战的 AI 增强版本。纯前端实现，零依赖，浏览器直接打开即可游玩。

## 怎么运行

```bash
# 方式一：直接打开
open index.html

# 方式二：起个静态服务（推荐，避免部分浏览器的 file:// 限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 技术选型

- **渲染**：HTML5 Canvas 2D，固定时间步长更新 + 插值渲染
- **逻辑**：原生 JavaScript（ES Module），不引入框架
- **资源**：图形全部用 Canvas 绘制，音效用 Web Audio 合成，不依赖外部素材

选原生而不是引擎，原因有三：零依赖便于演示、代码量可控、架构清晰便于评审。

## 架构（模块划分）

| 模块 | 职责 |
| --- | --- |
| `core/` | 游戏循环、时间步长、状态机 |
| `entities/` | 坦克、子弹、地形、道具；各自持有状态与更新逻辑 |
| `systems/` | 碰撞检测、输入、音效、关卡加载 |
| `render/` | 绘制层，只读游戏状态，不写逻辑 |
| `levels/` | 关卡数据，纯 JSON |

分工：单人项目，全部模块由本人设计。
